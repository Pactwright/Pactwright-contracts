# Test vectors (ADR-015)

The single source of truth for every hash in Pactwright. Rust (`contracts/pact/src/test/vectors.rs`)
and TypeScript (`@pactwright/core` `vectors.test.ts`) both run these files.

- Format: `{ "version", "formula", "cases": [{ "name", "input": {...}, "output": "<hex>" }] }`
- Generated by the contract crate (ROADMAP C-03); never edited by hand.
- Published as a release asset (C-18); the kit pins a release.
