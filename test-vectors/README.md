# Test vectors (ADR-015)

The single source of truth for every hash in Pactwright. Rust (`contracts/pact/src/test/vectors.rs`)
and TypeScript (`@pactwright/core` `vectors.test.ts`) both run these files.

- Format: `{ "version", "formula", "cases": [{ "name", "input": {...}, "output": "<hex>" }] }`
- Generated by the contract crate with `scripts/gen_vectors.sh`; never edited by hand.
  `cargo test` fails when a committed file drifts from the code.
- Exception: `condition_hash.json` comes from Pactwright-Kit (canonical JSON, Witness
  `conditionHash()`); the contract treats the condition hash as opaque bytes (ROADMAP K-03).
- Encoding: `xdr(x)` is the XDR of the value's `ScVal`; integers are big-endian; hex is lowercase.
  Signature cases include the signer seed, public key and signature so implementations can
  test signing and verification.
- Published as a release asset (C-18); the kit pins a release.
