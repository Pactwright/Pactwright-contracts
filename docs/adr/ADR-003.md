# ADR-003: Compact attestation bound to the Witness envelope hash (M2 only)

- **Status:** Accepted (2026-10-28)
- **Governs:** [ARCHITECTURE.md](../ARCHITECTURE.md) §4.2, §4.3, §6.5
- **Review items:** O7

## Context
Witness verdict-v1 envelopes are JSON signed with ed25519; canonicalising JSON on-chain is expensive.

## Decision
The verifier signs a compact `VerdictAttestation` (`pact_id`, `condition_hash`, `envelope_hash`, `verdict`, `amount`, `issued_ledger`) under the domain `pactwright-verdict-v1:`. The contract checks it with one `ed25519_verify`. The full envelope stays off-chain, bound by `envelope_hash`. Attestations exist only for M2; M0 uses the envelope alone.

## Consequences
- One signature check on-chain; envelopes remain readable by Witness tooling.
- Domain separation prevents reuse as a Witness verdict or a Stellar transaction.
