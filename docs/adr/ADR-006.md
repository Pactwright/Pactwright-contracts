# ADR-006: Agent wallet funded to the budget; top-ups; sponsored reserves

- **Status:** Accepted (2026-10-28)
- **Governs:** [ARCHITECTURE.md](../ARCHITECTURE.md) §6.2
- **Review items:** B5, B7, O10

## Context
Agents need a hard spending ceiling, and buyers should never have to buy XLM.

## Decision
The agent's balance is its ceiling: the principal funds it with the approved budget, in small top-ups. Agent accounts are created with sponsored reserves (CAP-33) and a USDC trustline.

## Consequences
- Overspending is impossible regardless of agent behaviour.
- "Revoke" means stop topping up; true revoke needs smart accounts (P9-04).
