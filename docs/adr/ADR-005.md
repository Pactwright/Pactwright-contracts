# ADR-005: Receipts anchored in batches by an off-chain anchorer

- **Status:** Accepted (2026-10-28)
- **Governs:** [ARCHITECTURE.md](../ARCHITECTURE.md) §6.6
- **Review items:** B14

## Context
Anchoring every receipt on-chain individually would cost a transaction per pact.

## Decision
The studio anchorer batches receipt leaves into a sorted-pair Merkle tree and calls `ReceiptAnchor.anchor_batch`. Certificates are `pending` until anchored.

## Consequences
- Cost is amortised; certificates verify offline and on-chain.
- The vendored ReceiptAnchor (v0.2.0) has no shards and a 1000-leaf batch limit (vendor/wasm/README.md).
