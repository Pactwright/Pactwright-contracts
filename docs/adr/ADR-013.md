# ADR-013: One receipt leaf per terminal transition

- **Status:** Accepted (2026-10-28)
- **Governs:** [ARCHITECTURE.md](../ARCHITECTURE.md) §4.3, §7.3
- **Review items:** edge case: refund after anchoring

## Context
An M0 pact can be paid and later refunded; one receipt per pact cannot represent both.

## Decision
Each terminal transition (paid, settled, released, refunded) produces its own leaf; `receipts.pact_id` is not unique.

## Consequences
- Certificates describe a transition, not only a pact.
