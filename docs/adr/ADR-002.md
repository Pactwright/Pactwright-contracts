# ADR-002: pact as admin of an upto-authorization instance (M1)

- **Status:** Superseded (2026-10-28)
- **Governs:** [ARCHITECTURE.md](../ARCHITECTURE.md) §2
- **Review items:** B1, O2

## Context
v0.1 made the `pact` contract the admin of its own `upto-authorization` instance so only the lifecycle could settle M1 payments.

## Decision
Superseded. M1 is deferred and Pactwright does not deploy or call `upto-authorization`.

## Consequences
- M1 returns only when Accensa's own ADR-002 resolves the `upto` construction on Stellar (concurrent allowances, buyer co-signing). Re-evaluating it is ROADMAP P9-06, which ends in a new ADR either way.
