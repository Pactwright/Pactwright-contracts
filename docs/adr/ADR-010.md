# ADR-010: Metering by signed cumulative usage vouchers; no verdict

- **Status:** Accepted (2026-10-28)
- **Governs:** [ARCHITECTURE.md](../ARCHITECTURE.md) §5.3
- **Review items:** O3, O4, O11

## Context
v0.1 used a PayWord hash chain: O(k) hashing on-chain and a CPU-derived unit cap.

## Decision
The buyer's SDK signs `UsageVoucher { pact_id, units }` (cumulative) with a per-pact `meter_key`; the seller submits the latest one to `close_meter`. Metered pacts never take a verdict. Metering runs in the SDK, not as an MCP tool.

## Consequences
- O(1) cost on-chain.
- Until `close_meter` ships (P7-01), `open` rejects metered pacts with `IsMetered`.
