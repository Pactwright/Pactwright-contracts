# ADR-014: Single verifier key in Config, snapshotted per pact

- **Status:** Accepted (2026-10-28)
- **Governs:** [ARCHITECTURE.md](../ARCHITECTURE.md) §4.4
- **Review items:** O5

## Context
v1 has one verifier operator; a registry with revocation history adds code without users.

## Decision
`Config.verifier` holds one ed25519 key; `open` copies it into the pact; `set_verifier` (admin) affects new pacts only.

## Consequences
- A key compromise affects open pacts until their `verdict_deadline`; short verdict windows are the mitigation.
- A registry returns when there is a second operator.
