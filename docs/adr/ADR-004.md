# ADR-004: pact x402 scheme and /pact/submit in the Accensa facilitator; no separate relayer

- **Status:** Accepted (2026-10-28)
- **Governs:** [ARCHITECTURE.md](../ARCHITECTURE.md) §5.2, §6.4
- **Review items:** B6, O6

## Context
M2 needs funding before delivery and sponsored submission of verdicts, settlements and releases. `ExactStellarScheme` rejects sub-invocations, and a standalone relayer would duplicate the facilitator's keys, rate limits and fee ceilings.

## Decision
Add a `pact` scheme to `accensa/x402-facilitator-stellar`: `/verify` validates an exact `pact.open` invocation, `/settle` funds the escrow, and `POST /pact/submit` sponsors an allow-listed set of `pact` calls.

## Consequences
- Keeps the standard x402 one-retry flow (latency about one ledger).
- The facilitator change is on the critical path (ROADMAP F-10, X-01…X-08).
