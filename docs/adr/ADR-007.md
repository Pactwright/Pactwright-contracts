# ADR-007: External projects behind adapters; MVP adapters first-party

- **Status:** Accepted (2026-10-28)
- **Governs:** [ARCHITECTURE.md](../ARCHITECTURE.md) §8.6
- **Review items:** O1

## Context
Pactwright composes seven projects, several of them hackathon code that may go unmaintained.

## Decision
Every external dependency sits behind an adapter interface (`Discovery`, `Reputation`, `Gate`, `Wallet`, `Verifier`). MVP implementations are first-party; Vespi, Pollar and BookerBob are add-ons.

## Consequences
- The MVP has no add-on dependency.
- Each add-on can be replaced without touching the core.
