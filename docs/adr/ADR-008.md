# ADR-008: Accensa contracts consumed as pinned, hash-verified WASM

- **Status:** Accepted (2026-10-28)
- **Governs:** [ARCHITECTURE.md](../ARCHITECTURE.md) §4.1, §11
- **Review items:** —

## Context
Pactwright depends on Accensa's `RefundVault` and `ReceiptAnchor`, built with a different soroban-sdk version.

## Decision
Vendor the WASMs built from a tagged Accensa release in `vendor/wasm/`, list their sha256 in `SHA256SUMS`, and check them in CI (`scripts/check_vendor_hashes.sh`).

## Consequences
- Currently pinned: Accensa v0.2.0 (`50ced70`).
- SDK versions are independent; interfaces are whatever the pinned release exposes, and upgrading is a deliberate change.
